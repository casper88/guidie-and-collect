# 01 — 願景與定位(重新評估後)

> 這份文件在 deep research(VLA 可行性 + 市場/競品)之後**重新定位**整個專案的目的與流程。
> 取代最初「幫某台機器人收資料」的想法。

## 一句話定位

> **G&C = 唯一同時做到「給工廠真實價值的作業引導」與「自動產出工業 contact-rich、含力覺、已標註的人類示範資料」的平台。**

研究顯示這個交集是**白地**:工作指引廠商只把資料給人看;機器人資料公司只記錄不引導、且幾乎都沒有力覺;公開資料集缺工業工件與力覺(見 `03_MARKET_LANDSCAPE.md`)。

## 為什麼是現在(Why now)

- **資料是瓶頸**已是共識(NVIDIA Jim Fan、Physical Intelligence、Bessemer);全球操作資料僅 ~30 萬小時,缺口被稱「10 萬年」。
- **工具鏈成熟**:LeRobot 成為訓練格式收斂點;可微調的開源 VLA(SmolVLA/π0/GR00T N1.5)可在消費級 GPU 跑;**Quest 3 原始相機 API 已可上架**。
- **工業 contact-rich 是最後一塊難啃但最值錢的資料**:>90% 線束/連接器裝配仍手工,幾乎無現存資料,且合成資料最難偽造。

## 目的(Purpose)——三層,缺一不可

1. **對工廠的當期價值(讓收資料有人買單)**:引導完全沒經驗的人完成插接/裝配工序,縮短上線時間、降低錯誤、品質可追溯。
2. **資料資產**:同一套引導,自動產出 embodiment-agnostic、含力覺、逐步語言標註的 master 資料。
3. **商業模式**:工廠自用(微調自家機器人),或授權/販售資料;G&C 提供平台與(可選)retarget 衍生 SKU。

## 定位的三條紀律(從研究直接得出)

1. **不比小時數**。Generalist/Build AI 在純量上贏不了。**守差異化:力覺 + 引導自動標籤 + 工業真實工件。**
2. **力 / 接觸是護城河,不是可選項**。插接是 vision-only + 純 kinematic 最弱的任務;沒有力覺的插接資料在 schema 中被標為低價值(見 `05_DATA_SPEC.md` 不變式 4)。
3. **誠實的價值主張 = 「省 demo 的乘數」**,不是「即插即用策略」。純人類資料無法單獨跨越 embodiment gap(EgoVLA zero-shot 0%);它讓買家**用更少機器人 demo 達標**。

## 重新評估後的流程(End-to-end flow)

```
[工廠] 用編輯器做「引導規劃」 ── guidance_plan.json (= 標註 schema)
        │
        ▼
[現場] MR 引導 + 同步擷取:egocentric RGB(D)、手部 26 joints、物件 6DoF、
        ★力/接觸★、事件、時間戳   ← 引導與擷取是同一個動作
        │
        ▼
[管線] 以 guidance_plan 為 schema 自動標註:語言指令、步驟切段、成功/失敗
        → 寫成 Episode master(embodiment-agnostic)→ 過驗證器(force 不變式)
        │
        ├──► [工廠自用] retarget → LeRobot → 微調 SmolVLA/π0/GR00T
        └──► [對外] 授權/販售 master(+ 可選 retargeted SKU)
```

與最初想法的差異:
- 從「**單一機器人**」→「**embodiment-agnostic 通用 master**,retarget 留給下游」。
- 從「錄影+手追就好」→「**力/接觸列為一等公民**」(否則對插接無差異化)。
- 從「收資料」→「**引導即標註**,自動產生語言/切段標籤,吃掉最貴的標註成本」。

## 北極星指標(North-star)

> **資料效率倍數**:在固定目標成功率下,「買家加入我們的資料」相對「只用自己的機器人 demo」,所需機器人 demo 數量**減少的倍數**。

這是 MVP(`06_ROADMAP.md` Phase 3)唯一要先證明的數字,也是對外銷售最有説服力的一張圖。研究中的參考量級:人類資料 +40% finetune 提升、GR00T 10% 資料達 4× 效果。
